# Controlador ASCII - Fluke Thermalert 4.0

Este projeto consiste em uma interface gráfica desenvolvida em Python para comunicação integral com os sensores infravermelhos da série **Fluke Thermalert® 4.0**.



## 🚀 Funcionalidades

- **Navegador de Comandos:** Acesso total aos 66 comandos do protocolo ASCII (Páginas 131-134 do manual).
- **Modos de Operação:** Suporte completo para modo **Poll** (interrogação) e modo **Burst** (leitura contínua).
- **Guia de Opções:** Descrições integradas para cada comando, exibindo valores legais e instruções de uso.
- **Console Manual:** Terminal para envio de comandos ASCII customizados.
- **Mapeamento Serial:** Detecção automática de portas COM disponíveis.

## 🛠️ Requisitos

- Python 3.x
- Biblioteca `pyserial`
